# 회계자료 검토 및 보고 보조 프로그램
### 회계자료 검토·보고 업무 지원 

> 회계자료를 **입력하는 프로그램**이 아니라, 제출 전에 **빠진 것·이상한 것·증빙이 필요한 것·사람이 확인해야 할 것**을 찾아 정리하는 프로그램입니다.

---

## 왜 만들었나요?

회사에서 회계자료를 정리할 때는 숫자만 입력한다고 끝나지 않습니다.

예를 들어 이런 확인이 필요합니다.

- 지출일자가 빠지지 않았는가?
- 금액이 0원이나 음수로 잘못 들어가지는 않았는가?
- 같은 결제가 두 번 들어가지는 않았는가?
- 사용목적이 제대로 적혀 있는가?
- 영수증이나 세금계산서가 있는가?
- 공급가액 + 부가세 = 합계금액이 맞는가?
- 확인이 필요한 건을 누가 언제까지 처리할 것인가?

이 프로젝트는 이런 반복 확인을 한 화면에서 관리하도록 만들었습니다.

> **회계는 숫자를 입력하는 일이 아니라, 숫자 뒤의 근거를 확인하고 신뢰할 수 있는 자료로 정리하는 일**이라는 관점에서 설계했습니다.

---

## 아주 쉽게 설명하면

```text
Excel / CSV 업로드
        ↓
열 이름 자동 인식
        ↓
누락·중복·금액·증빙 기준 검사
        ↓
확인할 항목만 모아서 보여주기
        ↓
담당자 / 기한 / 처리근거 기록
        ↓
제출 전 체크리스트
        ↓
월별 보고서 / 감사 대응 자료
```

즉,

> **“회계자료 제출 전 자동 검토 체크리스트 + 업무관리 프로그램”**

이라고 생각하면 됩니다.

---

## 주요 기능

### 1. 회계자료 자동 정리

CSV / XLSX / XLSM 자료를 업로드할 수 있습니다.

회사마다 열 이름이 달라도 다음과 같은 항목을 자동으로 찾아 제안합니다.

- 지출일자
- 금액
- 공급가액
- 부가세
- 거래처
- 사용목적
- 계정과목
- 부서
- 사용자
- 증빙번호
- 증빙여부
- 결제수단

자동 인식 결과를 바로 믿지 않고 **사용자가 직접 열 매핑을 확인한 후 저장**합니다.

같은 양식의 파일을 다음 달에 다시 올리면 이전에 확정한 매핑을 재사용할 수 있습니다.

---

### 2. 누락·중복·오류 자동 검토

기본 제공 검토 기준 예시:

- 지출일자 누락
- 미래 일자
- 금액 누락
- 0원 거래
- 음수 거래
- 고액 지출
- 사용목적 누락
- 사용목적이 너무 짧은 거래
- 증빙 누락
- 증빙번호 누락
- 공급가액 + 부가세 불일치
- 거래처 누락
- 계정과목 누락
- 정확 중복
- 중복·분할결제 의심

검토 기준의 **사용 여부·등급·기준값·표시 문구**는 관리자 화면에서 코드 수정 없이 바꿀 수 있습니다.

---

### 3. 원본까지 추적

오류가 발견되면 단순히 “오류 1건”으로 끝내지 않습니다.

각 거래에 다음 정보를 남깁니다.

```text
원본 파일명
원본 행번호
검토 기준
발견 내용
처리상태
담당자
처리기한
처리근거
```

그래서 나중에 **“이 숫자가 원래 파일 어디에 있었는가?”**를 다시 찾을 수 있습니다.

---

### 4. 확인·보완 업무 관리

검토 결과를 실제 업무로 연결합니다.

상태 예시:

```text
미확인
담당자지정
보완요청
재검토
확인완료
예외인정
```

담당자와 기한, 처리근거를 함께 남길 수 있습니다.

---

### 5. 증빙·문서 관리

PDF / DOCX / TXT / JPG / PNG 등의 문서를 등록할 수 있습니다.

증빙번호를 사용해 회계 거래와 연결합니다.

텍스트를 읽을 수 있는 문서는 키워드 기반으로 다음과 같이 분류합니다.

- 세금계산서
- 영수증
- 거래명세서
- 계약서
- 견적서
- 지출결의

**이미지 OCR 결과를 회계 사실로 자동 확정하지는 않습니다.**

---

### 6. 제출 전 체크리스트

자동 검토 기준 결과와 사람이 직접 확인해야 하는 항목을 함께 관리합니다.

예:

- 필수 열 누락 확인
- 증빙 누락 확인
- 중복 의심 확인
- 금액 불일치 확인
- 고액 지출 승인근거 확인
- 오류 등급 이슈 처리
- 최종 승인자 원본 확인

---

### 7. 월별 보고

월별로 다음 내용을 확인할 수 있습니다.

- 거래 건수
- 총 지출금액
- 미확인 이슈
- 오류 등급 건수
- 증빙 누락
- 중복 의심
- 계정과목별 금액
- 거래처별 금액
- 전월 대비 주요 증감 기여

단순히 “전월 대비 +20%”에서 끝내지 않고, **어떤 계정과목과 거래처에서 실제 금액 차이가 컸는지** 보여줍니다.

관측된 변화와 실제 원인은 구분합니다.

---

### 8. AI 보고 보조

AI에게 회계 계산을 맡기지 않습니다.

```text
Python / 검토 기준
→ 숫자 계산·검증

AI
→ 검증된 숫자의 설명·요약·보고 문장 보조
```

프로그램은 검증된 집계값만 사용해 AI 보고용 프롬프트를 만듭니다.

외부 AI 서비스로 원본 회계자료를 자동 전송하지 않습니다.

---

### 9. 코드 없는 관리자 설정

프로그램 안에서 다음을 변경할 수 있습니다.

- 프로그램명
- 회사명
- 메뉴명
- 메뉴 순서
- 메뉴 표시 / 숨김
- 주요 화면 문구
- 확인 요청 문구
- 검토 기준 사용 여부
- 검토 기준 중요도
- 기준금액 / 허용오차
- Rule 안내 문구

즉, 문구 하나 바꾸기 위해 Python이나 HTML을 수정하지 않도록 설계했습니다.

---

## 디자인

공개 Streamlit 화면은 **강한 타이포그래피, 넓은 여백, 모노톤 베이스, 원색 기하학 포인트**를 활용한 현대적인 UI 분위기를 참고해 회계 업무에 맞게 다시 설계했습니다.

- 오프화이트 배경
- 차콜/블랙 타이포
- 코발트 블루 핵심 액션
- 레드 오류 신호
- 옐로우 확인 포인트
- 직선형 카드와 넓은 여백

특정 서비스의 화면이나 로고를 복제하지 않고, 디자인 원칙만 참고해 독립적으로 구성했습니다.

# Streamlit에서 바로 체험하기

Streamlit Community Cloud 배포 후 README 상단에 공개 링크를 추가하면 됩니다.

앱 진입 파일:

```text
streamlit_app.py
```

배포 설정:

```text
Repository : 본인의 GitHub 저장소
Branch     : main
Main file  : streamlit_app.py
```

첫 실행 시 포트폴리오용 데모 데이터가 자동으로 준비됩니다.

---

## GitHub에서 실행하기

### 1. 저장소 다운로드

```text
Code → Download ZIP
```

### 2. Python 준비

Python 3.11 이상을 권장합니다.

### 3. 패키지 설치

```bash
pip install -r requirements.txt
```

### 4-A. Streamlit 화면 실행

```bash
streamlit run streamlit_app.py
```

브라우저에서 보통 아래 주소가 열립니다.

```text
http://localhost:8501
```

### 4-B. 기존 FastAPI 화면 실행

```bash
uvicorn app.main:app --reload
```

```text
http://127.0.0.1:8000
```

두 화면 모두 같은 핵심 검토 로직을 사용합니다.

## 프로젝트에서 보여주고 싶은 역량

이 프로젝트의 목적은 “AI를 썼다”는 것을 보여주는 것이 아닙니다.

### 회계자료 정확성
누락·중복·금액 오류·증빙 여부를 구조적으로 검토합니다.

### 분석력
월별 변화와 주요 기여 항목을 데이터로 확인합니다.

### 감사 대응
원본 파일·행번호·검토 기준·처리근거를 추적합니다.

### 보고 역량
검증된 수치로 월간 보고 초안을 만듭니다.

### 커뮤니케이션
확인·보완 요청 문구를 정리하고 담당자·기한을 관리합니다.

### AI 활용
AI를 숫자 판단자가 아니라 설명·요약·보고 보조자로 제한합니다.

### 업무 자동화

```text
입력
→ 검토
→ 이슈 발견
→ 담당자 조치
→ 처리근거 기록
→ 제출 / 보고
```

까지 연결합니다.

## 현재 한계

이 프로젝트는 완성된 상용 회계/ERP 시스템이 아니라 **포트폴리오용 MVP**입니다.

현재 다음 기능은 완성형으로 제공하지 않습니다.

- 세법 위반 자동 확정
- 자동 분개 최종 승인
- 이미지 영수증 OCR 결과 자동 확정
- ERP 실시간 API 연동
- 은행 / 카드사 실시간 연동
- 실제 회사 사용자 SSO / 권한관리
- 외부 LLM 자동 전송

특히 Streamlit Community Cloud의 로컬 SQLite 파일은 **영구 보존이 보장되지 않습니다.**

공개 링크는 포트폴리오 데모 용도로 사용하고, 실제 운영 시 PostgreSQL/Supabase 등 외부 데이터베이스를 연결하는 것이 적절합니다.

## 핵심 메시지

> **좋은 회계자료는 숫자가 많은 자료가 아니라, 숫자의 근거를 설명할 수 있는 자료입니다.**

이 프로그램은 사람이 반복 확인에 쓰는 시간을 줄이고, 중요한 판단과 커뮤니케이션에 더 집중할 수 있도록 돕는 것을 목표로 합니다.
